# Interaction

Interaction 根据有效反馈通过广义动量观测器估计外力，CSP 的柔性与拖拽模式使用该结果计算关节虚拟参考

| 部分 | 职责 |
| --- | --- |
| `estimators/` | 广义动量、零偏和摩擦模型及连续死区 |
| `controllers/` | M/D/K 虚拟模型、退让限幅与参数过渡 |
| `runtime/` | 观测与控制状态交换 |

MIT 由电机执行 PD，CSP 柔性与拖拽以名义参考叠加导纳位移后发送位置命令；CSP 刚性与伺服跟踪直接跟随名义参考

`InteractionState` 交换外力估计、导纳位置与速度修正及有效性；`RobotCycleOutput` 额外记录名义、虚拟、最终参考、测量时序与限制标志

观测器只在有效新测量上推进；零偏和摩擦在动量观测器内按相同符号处理，不加入 CSP 命令；FULL-ID 残差仅供诊断

`JointAdmittanceController` 使用后向 Euler 积分；柔性使用正刚度，拖拽使用零刚度及正阻尼；限制后的接受状态回写控制器，运行中更新保留状态并平滑过渡

M/D/K 决定虚拟响应，执行器带宽、延迟、模型误差和限制共同影响实际响应；接触行为按具体任务验证

任务方向、插入约束和操作流程由应用层定义；完整链路见 [开发与架构](../../../../../../docs/development.md) 与 [API](../../../../../../docs/reference/api.md)
