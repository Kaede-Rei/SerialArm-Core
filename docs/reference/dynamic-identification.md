# 完整动力学辨识与实验流程 · v2

工作台「动力学标定 → 完整辨识」按 **数据检查 → 辨识设置 → 结果与推荐 → 导出** 使用；常用操作不会重建 3D 视图、丢失相机或滚动位置；可信 Link 是完整辨识自己的状态，勾选代表固定，不等于只导出其他 Link

## 采集与实时控制

正式采集沿已经检查、重定时的示教路径，执行逆向静态、正向静态、逆向半速、正向半速、逆向计划速度、正向计划速度；运动部分约为单程的 8 倍，另加双向静态停留

采集完成先确认保持并恢复正常运行时配置，停止记录器后发布任务完成；不再在 ACTIVE 会话中深拷贝全部历史帧、逐帧更新实时动力学对象或拟合摩擦；控制生产队列与静态发布/历史归档使用不同锁；ACTIVE 记录器的全量快照直接拒绝

在线静态预览只作快速诊断；保留先验时明确标记 `prior_retained`，不作为有更新的模型通过或启用应用按钮；最终结果来自保存后的统一离线分析，收尾不再自动生成摩擦配置

采集中显示双向到位位置差与组数；超过 0.01 rad 的组提示重复性问题，但原始观测仍保存；这个门限是提示，不是通过降低门限制造精确摩擦抵消；故障保持和 50 ms 反馈超时门限保留

## 静态数据契约

`static_observations.py` 是静态重力与完整 IDIM 共用的数据读取器

- 新记录只读 `accepted_static.csv`；每方向至少 30 帧，取末端最多 60 帧的中位数；检查有效值、反馈年龄 ≤30 ms、速度 <0.04 rad/s、方向和训练/验证标签
- 保留各方向的实际 q，不先平均关节角；先计算各方向回归矩阵和力矩，再按姿态组等权平均
- 同一姿态的两个方向属于同一个训练或验证组，不能把一方向当训练、另一方向当验证
- 双向半差、组内 MAD 用作迟滞不确定性；双向位置不同不声称精确摩擦抵消；单向组保留并赋更大的不确定性
- 0.02/0.05 Nm 是明确声明的双向/单向评分尺度下限，不是传感器噪声实测值；报告保留方向、实际位置差和不确定性

## 联合数学模型与物理拟合

使用实际 q 的四阶零相位 Butterworth 位置滤波（默认 5 Hz；2/10 Hz 为敏感性配置），独立连续约 10 秒块重采样、中心差分得到 v/a；不读取在线 `acc`，也不用参考轨迹导数替代实际状态；遇无效值、阶段变化或 >25 ms 间隔切段；各块去掉 1.5 秒边缘，回归和响应同样 5 Hz 低通并降到约 20 Hz

运动方程为 `tau = Y(q,v,a) theta + b + Fc sign(v) + Fv v + residual`，各轴主要运动方程要求 `|v|>0.03`；静态组以实际姿态的 `Y(q,0,0)` 和静态观测加入同一个训练目标；静态方程不把 Coulomb/粘性项伪装成已知静摩擦

每 Link 的质量分布矩阵为 `J = [[0.5 tr(I_O) Id - I_O, h], [h^T, m]]`；在源模型 Cholesky 同余归一化下直接约束 `J` 正定，使用 CVXPY/Clarabel 求解；不先冻结错误的可观察参数再只补零空间，不裁剪参数，不设置质量上界或质心经验硬边界；源模型不提供严格物理参考时明确报错

全局与局部使用相同模型和预处理；局部从构造系统开始固定可信 Link，固定块不进入优化；输出完整模型，不做全局求解后 mask，不摘取某个 Link 拼接；惯性从 Link 原点参数正确转换到 COM 再写入 URDF

软正则是源质量分布同余坐标的 Frobenius 距离；系数 `{0.01,0.1,1,10,100,1000}` 及“不更新”由训练集内部三折选择；每折同时留出完整时间块和整个静态姿态组，外部验证会话和本次静态留出组不参与选择

默认 WLS 使用同一个训练源模型残差归一化尺度比较不同范围；这不是已知传感器协方差；OLS 使用统一轴尺度；IRLS 选项先用迭代 Huber 诊断权重再做物理约束重拟合，报告明确记录这一变体，不声称逐行复现 BIRDy

基线和候选的偏置/摩擦都仅在同一训练静态+运动系统估计，再冻结用于验证；纯重力评分不添加拟合偏置；动态预测改善不等于重力补偿改善

方法参考：[IDIM 基准](https://doi.org/10.3390/app11094303)、[物理惯量 LMI](https://arxiv.org/abs/1701.04395)、[参数可观察性](https://arxiv.org/abs/1711.03896)

## 推荐模型与拟合候选

即使交叉验证推荐保留输入模型，也保留最佳收敛物理拟合为**不被推荐的审核对照**，显示 `recommendation=keep_source_prior`；这不等于自动采用它，也不把原模型重新命名成新模型

报告区分别展示质量、COM、完整惯量差值、运动误差、纯重力误差、物理性及缺少的输入条件；3D 使用完整候选的一阶矩与质量作只读质心对照；几何绑定不同或不明确时不显示不可信的对照

未采样的夹爪关节必须全程固定；已知时显式声明实际位置，未知时仅按中立位诊断并保留假设；装机说明可补充为单列的操作者声明，不能与已记录条件冲突，不改原始 metadata，也不把补录声明当作测量

## 三种导出

1. **诊断报告**：始终可导出，含完整报告、SHA 收据、原始/拟合/无约束对照参数；不含 URDF
2. **待审核 URDF**：模型必须物理有效，校验完整惯性参数回读和 FK；可以尚缺独立会话或条件声明，但附明确缺项，不作为硬件应用或改善认证
3. **通过离线检查的模型**：另需独立会话、相同模型/装机/映射/重力/量程、输入质量通过、未采样关节位置已知、运动与纯重力改善且训练 CV 不推荐保留原模型；仍不等于真机验收

三者都不改 Core YAML、observer 偏置或当前运行模型；没有自动应用；非物理解不能作为待审核 URDF 导出；报告或源数据哈希变化拒绝导出；目标目录不覆盖

## 下一步实验：先缩小证据缺口，不批量重采

1. 重启已安装的工作台；保留已知可用整份 URDF 作对照，先不装新的待审核候选；固定控制参数、装机、夹爪和载荷
2. 先核对力矩反馈的独立量纲依据：选择若干可重复静态姿态，用已知质量及安装位置做增量载荷对照；保持相同实际姿态，记录每轴 q/tau、时间、控制配置、载荷位置与重复结果；理论增量为 `Jv(q)^T * delta_m * g`，核对符号、量级及重复性，不能只凭 PMAX/VMAX/TMAX 读回就宣称物理 Nm 已标定
3. 同时核对双向到位实际位置差、迟滞和夹爪固定位置；差异过大时先处理可重复观测，不把两方向当精确摩擦抵消
4. 只有这些检查通过，再采一轮独立会话用于现有模型的跨会话验证；在离线结果明确支持更新前不批量采集、不逐个换 URDF 猜效果
5. 模型有离线证据后，分别比较纯重力保持/漂移和运动预测；用固定工况量化，不用视频手感替代记录；保留反例与失败姿态
